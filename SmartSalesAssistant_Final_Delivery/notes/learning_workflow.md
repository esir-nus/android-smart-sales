# Project-Centered Learning Workflow

Use this whenever you want a guided tour of a concept tied to the Smart Sales Assistant repo.

1. **Setup**
   - Tell the agent the topic (e.g., "BLE scanning") and your goal (understand/modify/debug).

2. **Prerequisites & Relevant Info**
   - Agent lists background knowledge, files, or tools you'll need so you're never guessing.

3. **Explain (Lego Analogy + Glossary)**
   - Plain-language breakdown plus short definitions of important terms.

4. **Explore the Code**
   - Walk through the actual files/modules in this repo to see the concept in context.

5. **Quiz or Check-In (Optional)**
   - Quick question to reinforce learning. You can answer, skip, or ask for hints.

6. **Apply**
   - Suggested mini-task (e.g., trace a function, tweak a constant) so you practice on the real project.

7. **Summarize + Learning Progress**
   - Recap the key idea, log the milestone, and show the "Learning Progress Bar" so you know how far you've come.

Call this kit any time by saying "Start workflow on <topic>".
