## 🚀 如何运行测试页面

### Step 1: 确保文件结构正确

创建以下目录和文件：

```bash
app/src/main/kotlin/com/salesassistant/zhinengxiaoguan/
├── presentation/
│   ├── main/
│   │   └── MainActivity.kt
│   └── test/
│       ├── TestScreen.kt
│       └── TestViewModel.kt
```

### Step 2: 复制代码

将上面生成的三个文件复制到对应位置：
1. `MainActivity.kt` 
2. `TestScreen.kt`
3. `TestViewModel.kt`

### Step 3: 同步Gradle并编译

```bash
# 在项目根目录执行
./gradlew clean build
```

### Step 4: 运行应用

在Android Studio中：
1. 连接设备或启动模拟器
2. 点击运行按钮 ▶️
3. 等待应用安装和启动

## 🐛 常见问题排查

### 问题1: 应用崩溃，提示 "Cannot find symbol: TestViewModel"

**原因**: ViewModel文件未创建或包名不正确

**解决**:
1. 确认`TestViewModel.kt`在正确位置
2. 确认包名是`com.salesassistant.zhinengxiaoguan.presentation.test`
3. 同步Gradle并Rebuild

---

### 问题2: API密钥显示 "❌ 未配置"

**原因**: `local.properties`文件未创建或格式错误

**解决**:
1. 在项目根目录创建`local.properties`文件
2. 添加以下内容：
```properties
DASHSCOPE_API_KEY=sk-3617a0cf4daa4428a17c990e8307f09c
TINGWU_APP_KEY=DVi4nadRWfUuGj2g
```
3. Rebuild项目

---

### 问题3: FastBle显示 "❌ 未初始化"

**可能原因**:
- 使用的是模拟器（模拟器通常不支持BLE）
- 设备蓝牙未开启
- 权限未授予

**解决**:
- **如果是模拟器**: 这是正常的，模拟器不支持BLE
- **如果是真机**: 
  1. 确保蓝牙已开启
  2. 授予应用蓝牙权限
  3. Android 12+需要授予"附近设备"权限

---

### 问题4: 点击日志按钮，Logcat无输出

**原因**: Logcat过滤器设置问题

**解决**:
1. 清除Logcat过滤器
2. 在搜索框输入：`tag:TestViewModel`
3. 或选择Log Level为 "Verbose"

---

### 问题5: UI颜色不是蓝色系

**原因**: 主题未正确应用

**解决**:
1. 检查`MainActivity`是否使用了`SalesAssistantTheme`
2. 检查`Color.kt`文件是否正确导入
3. Rebuild项目
