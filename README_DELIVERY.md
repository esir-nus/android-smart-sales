## 🐛 TROUBLESHOOTING

### Common Issues

**Issue**: Gradle sync fails  
**Solution**: Check internet connection, invalidate caches

**Issue**: Build errors  
**Solution**: Clean project, rebuild

**Issue**: API calls fail  
**Solution**: Verify API keys in local.properties

**Issue**: BLE not working  
**Solution**: Check Bluetooth permissions, enable Bluetooth

**Issue**: File sync fails  
**Solution**: Check WiFi connection, device accessibility
